# RoomBreak Escape Now

![RoomBreak Escape Now 타이틀 화면](media/title.png)

## 다시, 그 문을 열다

《RoomBreak: Escape Now!!》는 GAMEDAY의 스토리 중심 방 탈출 게임으로, 미국 iOS 버전은 [2011년 9월 23일 출시](https://gamefaqs.gamespot.com/iphone/644223-roombreak-escape-now/data)되었습니다. 여섯 이야기와 서른 개의 스테이지에서 단서를 찾고, 아이템을 조합하고, 장치를 풀고, 망치와 칼 같은 도구로 다음 장소를 향해 나아갑니다.

원작은 초기 모바일 기기와 오래된 실행 환경에 의존하여 오늘날의 휴대전화나 컴퓨터에서 다시 즐기기 어려워졌습니다. 이 프로젝트는 **macOS, Windows, Android, iOS용 네이티브 앱**을 목표로, 익숙한 방과 소리, 이야기를 오늘날의 휴대전화와 컴퓨터에서 다시 즐길 수 있도록 만드는 작업입니다.

한국 기업 정보 사이트 비즈노에는 GAMEDAY Inc.(사업자등록번호 617-81-59967)가 [2021년 2월 17일 폐업](https://bizno.net/article/6178159967)한 것으로 기재되어 있습니다. 이는 해당 사이트에 수록된 사업자 상태이며, 원작 콘텐츠의 권리는 계속 각 권리자에게 있습니다.

## 지금 즐기는 방법

- 여섯 에피소드와 서른 개의 본편 스테이지. 튜토리얼, 이야기, 아이템 조합, 퍼즐 미니게임 포함.
- 게임 내 중국어, 영어, 일본어, 한국어 지원. 마우스와 터치 조작 지원.
- 상점 상품은 오프라인에서 무료로 받을 수 있으며, 원래 상품별 수량을 유지하고 반복 수령 가능.
- 새 저장 파일의 초기 아이템 수량은 원작과 동일. 이후 획득과 소모는 저장되며 재시작해도 초기화되지 않음.
- 상점의 ‘모든 스테이지 해제’ 버튼은 확인 후 실행.
- 황금 열쇠는 스테이지에서 한 번만 수집하는 아이템이며, 획득 여부는 저장 파일에 기록.

## 익숙한 조작, 새로운 구현

원작 iOS 게임은 **Objective-C와 cocos2d**를 사용하여 32비트 iOS와 OpenGL ES를 대상으로 제작되었습니다. 이번 버전은 **C++와 Axmol 2.11.5**로 실행 기반을 다시 작성하여 장면, 이야기, 아이템, 퍼즐, 오디오, 저장 기능을 네 플랫폼에서 공유하고 현대적인 그래픽 백엔드를 사용합니다.

원작 금고 다이얼의 문제도 수정했습니다. 기존 구현은 한 단위보다 작은 드래그 이동량을 0으로 잘라 버려, 천천히 미세하게 움직일 때 반응하지 않을 수 있었습니다. 새 구현은 부동소수점 정밀도를 유지하여 작은 움직임으로도 다이얼을 돌릴 수 있습니다. 화면 글자는 기존 글꼴 스타일을 유지하면서 고해상도 창에서 더 선명하게 표시됩니다.
