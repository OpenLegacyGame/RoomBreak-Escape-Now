# RoomBreak Escape Now 全ステージ攻略

ステージ選択画面の順に、全6章・30ステージを解説します。手がかりの発見、考え方、操作、脱出までを順に説明し、各ステージの収集用ゴールドキーも記載しています。ゲーム画像、美術、物語の権利は GAMEDAY Inc. および各権利者に帰属します。

## 操作のコツ

部屋を左右にドラッグすると画面外を見られます。調査、取得、アイテム使用、移動は別の操作です。開いたドアを通るときは移動モードに切り替えてください。所持品の合成モードではアイテムを別のアイテムに重ね、分解モードでは包みや道具、食べ物を分けます。アニメーションが終わってから次へ進みます。

数字式金庫には、入力後にハンドルを下へ引くものがあります。ダイヤル錠は各桁を中央に合わせます。ハンマーは出現する的をタップし、切断は指示方向にスワイプします。ショップの補助アイテムは無料で繰り返し受け取れます。自由に選択したい場合は、ショップで全ステージ解放を確認できます。

収集用ゴールドキーは収集進捗に一度だけ加算されます。鍵穴に使う金色の鍵は謎解き用アイテムです。画像には操作途中のものもあるため、最終設定は本文に従ってください。

## 第1章：部屋に残る思い出

### 1-1：写真の日付

1. テレビで妻のメッセージを聞きます。記念日の話が出るので、日付が残っている物を探します。
2. 化粧台のブラシを取り、ほこりをかぶった写真を調べます。額にブラシを使い、拡大画面を左右にこすって日付を出します。
3. 写真は **08.17**。金庫は4桁なので、点を除いた **0817** を入力します。
4. ハンドルを下げて鍵を取り、出口に使います。ドアを開け、移動モードで出ます。

**ゴールドキー：** 手前の丸テーブルの縁、写真の右側で日記の隣。取得モードで拾ってから出ましょう。

### 1-2：扇風機からメモを出す

1. テレビを見て扇風機を調べます。ボタンがなく、そのままでは動きません。
2. 床のペンチとハンガーを取り、合成してフックにします。ベッド下の狭い場所に届く道具です。
3. ベッド下にフックを使ってボタンを取り、扇風機に取り付けて動かします。
4. 羽根が回ってメモが落ちたら拾います。書かれた **6614** が金庫の暗証番号です。
5. **6614** を入力してハンドルを下げ、鍵でドアを開けて移動します。

**ゴールドキー：** 右へスクロールした先のパソコン机。キーボードの左、机の手前の縁にあります。

### 1-3：曲名、演奏時間、照明の影

1. テレビを見て、ベッド付近のバレリーナを取ります。地球儀付近の棚からCDケースを取り、分解してCDとケースにします。
2. 人形をオルゴールに置き、点灯した表示を調べます。曲名は **You are my Everything**。
3. CDケースの曲目表で同じ曲を探すと、長さは **03:27**。金庫に **0327** を入力してハンドルを下げ、変わった形の鍵を取ります。
4. 台所の戸棚からハンマーを取ります。壁の照明を左へ向けると鍵穴が現れます。
5. 変わった鍵を照明に使います。壁に投影された影が叩く場所を示すので、そこにハンマーを使います。
6. 壁の中の普通の鍵を取り、出口を開けて出ます。

**ゴールドキー：** 一番右にある赤い台所収納の引き出し。下の戸棚だけでなく引き出しも開けてください。

### 1-4：3本の鎖を外す

1. ドアの鎖はテレビ、ラジオ、オルゴールに対応します。まずテレビを繰り返し操作して、点灯と鎖の解除まで進めます。初期状態から4回です。
2. 台所の引き出しの電池をラジオに入れ、電源を入れると2本目が外れます。
3. 接着剤と人形の破片2つを集めます。破片同士を合成し、接着剤を加えてバレリーナを修理します。
4. オルゴールの円盤を回し、赤い十字が正立し、下部の暗い背景がつながるように絵を合わせます。完成後に人形を置き、オルゴールと表示の反応を待つと残りの鎖が外れます。
5. Beatlesのポスターを調べ、服の数字を左から **1、9、6、3** と読みます。金庫に **1963** を入力し、ハンドルを下げます。
6. 鍵を取り、3本とも外れていることを確認して出口を開け、移動します。

**ゴールドキー：** 右側の台所テーブルにある果物皿の中。そのまま拾えます。

### 1-5：日記が示す6つの隠し場所

1. テレビを見て丸テーブルの日記を読みます。2ページのリンゴ、地球儀、鏡、ソーセージ、クマ、額縁は、ドア横の6個のハート型の鍵の隠し場所です。
2. 包丁と床のハンマーを取ります。クマを包丁で切り、指示のスワイプを終えてハートの鍵を取ります。
3. 鏡、地球儀、額縁をそれぞれハンマーで壊し、鍵を1本ずつ取ります。
4. 冷蔵庫のソーセージを分解して鍵を取ります。テーブルのリンゴは包丁と合成し、最後の鍵を出します。
5. 6本をドア横の対応する穴へ入れます。仕掛けが解けたら金庫を開け、古い鍵を取ります。
6. 出口に古い鍵を使うと折れます。ドアにハンマーの操作を2回行って開け、通り抜けます。最後のドアも開けて章を終えます。

**ゴールドキー：** 手前の丸テーブル、写真の右でランプの台座付近。ハートの鍵とは別に拾います。

## 第2章：現場の手がかりを追う

### 2-1：ブラインドの向こうの数字

1. 机のハンマーでガラスの花瓶を壊し、小さな鍵を取ります。これで引き出しを開けます。
2. ドライバーセットを取り、2回分解してブラインドの制御箱に合う星形ドライバーを出します。
3. 金属箱のねじを外し、制御装置を操作してブラインドを開けます。ねじを外した後にさらに2回タップします。
4. 窓に現れる数字を順に読むと **0、2、1、3**。ダイヤル金庫の暗証番号です。
5. 左から **0213** に合わせ、各数字を中央に置きます。中の鍵で出口を開けて出ます。

**ゴールドキー：** 出口横の小窓をハンマーで割ると取れます。大きなブラインドの右側の窓です。

### 2-2：血痕からメッセージを読む

1. 床の金属板と警察の道具袋を取ります。最初から持っている袋の鍵と合成して開け、繰り返し分解して説明書、噴霧器、ルミノール試薬を取り出します。
2. 説明書から、試薬をかけた血痕が暗闇で見えると分かります。噴霧器と試薬を合成します。
3. 金属板でテレビ台の引き出しをこじ開け、ハサミを取ります。規制テープを切ると血痕に近づけます。
4. 血痕に噴霧し、照明を消します。光る文字の **7230** を読みます。隣の名前も、残されたメッセージであることを示しています。
5. 照明を戻し、ドア横の電子錠に **7230** を入力します。解錠後に開けて移動します。

**ゴールドキー：** 同じ金属板で、テレビ台下部のもう一方の引き出しを開けます。ハサミを取った後も調べましょう。

### 2-3：目線の方向をたどる

1. カッターで絵の覆いを切り、絵を調べます。目線の順は **上、下、左、右、上、右** です。
2. 矢印装置をその順に6回押し、小さな鍵を取ります。忘れたら絵をもう一度見ます。
3. 鍵で両側の戸棚を開け、ドリルと電池を取って合成します。
4. 暖炉が出口ですが、火が邪魔です。空き缶を取り、ドリルで水槽に穴を開け、流れる水を缶で受けます。
5. 暖炉に水をかけて消火します。小さな踏み台を取り、暖炉を調べて中に置き、上の通路に届く足場を作ります。
6. 設置した踏み台を調べ、移動モードで登ります。

**ゴールドキー：** 右側の絵の下にある木製収納の引き出しを開けて取ります。

### 2-4：骸骨の絵と3つの計算

1. ドアの **6412** を確認し、表示器の骸骨の絵を6枚すべて見ます。各絵の番号と外見を対応させます。
2. 右のロッカーからレンチを取り、鉄パイプを固定する2本のボルトを外します。パイプで錠のガラスカバーを割ります。
3. 骸骨ボタンを **6→4→1→2** の絵の順に押します。位置では **下段左、下段右、上段右、上段左**。解錠したら次の部屋へ。
4. パソコン机の引き出しの電源コードをコンセントにつなぎます。表示器の3ページがA・B・C金庫のヒントです。
5. **A：** 数字表の各行・列の合計が30になるよう空欄を求めます。下の **緑、赤、青、黄** の順に **1、8、5、6** を読み、**1856** を入力します。
6. **B：** 下の凡例にある4種類の星を別々に数えます。順に **7、5、5、3** 個なので **7553**。
7. **C：** 各扇形の3数字の合計は18。緑、赤、青、黄の順に18−4−8=6、18−5−9=4、18−7−2=9、18−8−6=4となり、**6494** です。
8. 金庫から大・中・小の歯車を取り、出口装置に入れます。絵が正立してつながるように回し、完成したら出ます。

**ゴールドキー：** 最初の部屋で左ロッカーのドライバーを取り、左壁の金属板を外して拾います。次の部屋へ行く前に回収します。

### 2-5：スイッチ配置図を完成させる

![配電盤スイッチ](assets/switch.png)

1. カーテンを開け、会話を終えます。本を調べて開き、小さな鍵で引き出しを開け、二連銃を取ります。倒れた椅子の近くでメモ片1を拾います。
2. 番号ロッカーを調べます。1番のプラスチック箱を分解すると弾薬、3番には電線があります。先に電線を取ります。
3. 横のヒントに従い、**1・4番を開け、2・3番を閉める** と5番が開き、メモ片3を取れます。両組の番号の和は5。開閉を逆にしても解錠できます。
4. 銃と弾薬を合成し、通路のドアに2回使います。廊下に入り、ペンチとベンチ付近のメモ片2を取ります。
5. 3枚を合成すると、上下2段・各5個の枠の図になります。配電盤の10スイッチに対応し、黒い側がレバーの位置を示します。
6. ペンチと電線を合成して両端を加工し、配電盤に取り付けます。
7. 左から **上段2・5、下段2・4・5** をオン、残りをオフにします。装置が復旧したら出口を開けて出ます。

**ゴールドキー：** **6番** ロッカーの中。最初の部屋を出る前に取ります。
## 第3章：指紋と隠し通路

### 3-1：ボタンを特定し、指紋を写す

1. 出口横の装置を調べます。ボタン入力と指紋認証が必要ですが、ボタンの指紋はまだ見えません。
2. ペン立ての筆とアルミ粉の瓶を合成します。引き出しからテープ、机からインク台も取ります。
3. 粉をつけた筆を装置に使います。拡大画面で指紋が現れる **0、1、6、7** の4ボタンを選び、走査を待ちます。
4. 本人の指紋も必要です。上司が最後に押した警報スイッチを調べます。
5. テープを分解して切れ端を取り、インク台と合成します。それを警報スイッチに使い、指紋を写したテープを作ります。
6. 認証装置にテープを使い、成功したらドアを開けて移動します。

**ゴールドキー：** 上司が座る椅子の座面の手前、机の下に近い位置。そのまま拾います。

### 3-2：投影された色を数える

![電気回路](assets/circuit.png)

1. ソファ下のハンマーでDVD棚のガラスを割り、電池を取ります。テーブルのリモコンと合成し、壁の投影機に使います。
2. 壁に示された色順で投影図を数えます。**青4、黄5、赤4、緑5** なので金庫番号は **4545**。
3. 金庫はスクリーンの裏ですが、昇降装置に電気がありません。右の引き出しのドライバーで回路箱のねじを外し、ふたを開けます。
4. 最初の点灯箇所から隣接点を **右、上、右、右、右、右、下、左、左、左、下、右、右、下、右、上、右、上、右、上** の順につなぎます。1点ごとに点灯を待ちます。
5. 復旧後に昇降装置でスクリーンを上げます。金庫に **4545** を入力し、ハンドルを下げて鍵を取ります。
6. 出口を開けて移動します。

**ゴールドキー：** テーブル右側のガラスの下。まずハンマーでそのガラスを割ってから拾います。

### 3-3：楽譜の隙間にある数字

1. 壁の楽譜を拡大し、横へドラッグして全体を見ます。音符や線の間の余白が数字になっています。矢印の向きに読むと **4710**。
2. タブレット装置に **4710** を入れ、開いた収納から火薬と導火線を取ります。引き出しから青いテープとライターも取ります。
3. 冷蔵庫から鍵入りの氷、コンロ付近からピンセットを取ります。鍵を出すには氷を溶かします。
4. ガラスのやかんに氷を入れて対応するコンロを点火します。溶けたらピンセットで熱い水から鍵を取ります。
5. 所持品で火薬と導火線を合成し、青いテープを加えてこの場面の爆薬アイテムにします。台所の出口に貼り、ライターでドアが開くイベントを進めます。
6. 壊れたドアを通って廊下へ戻り、取り出した鍵で衣装部屋を開けます。

**ゴールドキー：** 冷蔵庫の中。氷と一緒に回収します。

### 3-4：BLUE SHIRTからVASEへ

![時計の仕掛け](assets/watch.png)

1. 衣装部屋の床のメモを取り、**4、1、8、12 / 9、7、5、2、10** を記録します。床模様と中央ドアの9マスを比べます。
2. **左上、右上、中央、右下** を点灯させると通路が開きます。書斎へ入ります。
3. 短刀を取り、番号付きの本の背を調べます。メモ順に4=B、1=L、8=U、12=E、9=S、7=H、5=I、2=R、10=Tとなり、**BLUE SHIRT（青いシャツ）**。
4. 戻って青いシャツを短刀で切り、小さな鍵を取ります。中央の収納を開けると4個の腕時計が現れます。
5. 書斎の方位磁針と壁時計を調べます。赤い方位針は北、時計の赤い針は5時方向。5時方向を北として腕時計を読むと **W、S、N、E** です。
6. 時計下の文字を **W、S、N、E** にします。初期状態からのタップ回数は **1、2、3、0**。成功すると針が **3、6、9、12時** を指します。
7. 本の背で再び数字を引くと3=V、6=A、9=S、12=E。文字金庫に **VASE（花瓶）** を入れ、花瓶を取ります。
8. 花瓶を調べて分解し、中の鍵を取り出します。廊下へ戻り、居間のドアを開けます。

**ゴールドキー：** 衣装部屋右側の開いた棚の畳んだ服を短刀で切ります。青いシャツの普通の鍵と両方回収します。

### 3-5：色の照明、コルク、窓からの脱出

![コルクの4本線](assets/clues/wine-cork.png)

![ワイン棚](assets/wine.png)

1. 居間のテーブルのハンマーを取ります。窓から出るにはブラインドを上げ、ガラスを割り、長いロープを用意します。
2. 廊下から台所へ戻り、包丁とコルク抜きを取ってカーテンを切ります。衣装部屋では引き出しのペンチ、棚の金属ハンガーとダイヤの首飾りを取り、ここのカーテンも切ります。
3. 隠し通路から書斎へ入り、3枚目のカーテンを切ります。居間に戻り、2枚を合成してから3枚目を加え、丈夫なロープにします。
4. ペンチとハンガーを合成して短い針金にします。冒頭の会話後は左壁のヒューズ箱が解錠済みです。手で開け、欠けたヒューズの位置に針金を入れます。
5. 補助照明をつけて主照明を消し、暗闇に現れる色模様の外周と中央を覚えます。その後主照明を戻します。
6. ワイン棚に同じ配置を作ります。外周は一番上から時計回りに **緑・赤を交互**、内側の左右は両方 **緑**。状態は消灯→赤→緑で、中央ボタンはリセットです。
7. 棚の赤ワインを取り、コルク抜きと合成します。コルクの4本線は **1111**。ブラインドのヒント **RED WINE** と対応するので、**1111** を入力します。
8. 現れた窓ガラスにダイヤの首飾りで傷をつけ、ハンマーで割ります。
9. 窓に丈夫なロープを設置し、移動モードで降ります。

**ゴールドキー：** 居間のバー左側の細口のガラス花瓶。ハンマーで割って拾います。

## 第4章：遺跡のメッセージ

### 4-1：石板どおりに赤青の球を置く

1. 床のハンマーで岩を割り、ボタンを押します。現れた壁画の宇宙人4か所をすべて調べると、左のUFO収納が開きます。
2. 青い球の束を取り、繰り返し分解して6個にします。
3. 右の石板を調べます。青6個は六芒星の外側の頂点、赤4個は内側の小さな正方形の角です。
4. 青を壁の外側6穴、上・下・左上・右上・左下・右下へ置きます。内側4穴は空けます。
5. 変化した宇宙人の壁画4か所をハンマーで割り、赤い球を取り、中央の正方形の穴へ入れます。
6. 床から浮いたペンダントを取り、壁中央の **Pendant** と書かれた位置に使います。石扉を待って出ます。

**ゴールドキー：** 左のUFO収納の右隣にある、小さく光る壁模様。その壁をハンマーで割ります。

### 4-2：1324をレンガの位置に変える

![ピラミッド](assets/pyramid.png)

1. ハンマーと金色の飛行機を取ります。右のUFO収納の飛行機形のくぼみに入れ、プラグ形の化石を取ります。
2. スフィンクスの差し込み口をハンマーで開け、化石を入れます。片目だけ正常に光るため、もう片方を直します。
3. 右目の半球を外し、宇宙人模様の異常な床タイルを割ってもう半分を取ります。合成した球を右目に入れます。
4. 両目の光で **1324** が完成します。4桁はピラミッドの各段で押すレンガの番号です。
