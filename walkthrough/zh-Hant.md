# RoomBreak Escape Now 全關卡攻略

以下按遊戲選關畫面的六章順序排列，包含全部三十個正式關卡。每關按線索發現、推理、操作與離開房間的順序展開，並單獨說明收集黃金鑰匙的位置。圖片中的遊戲畫面、美術與劇情歸 GAMEDAY Inc. 及相應權利人所有。

## 操作秘訣

左右拖動房間可以檢視螢幕外的物品。調查、拾取、使用物品和移動是不同操作；門已開啟時，記得切換到移動模式。物品欄中選擇組合模式，將一個物品拖到另一個物品上；拆分模式則用於拆開包裹、工具或食物。等待動畫結束後再進行下一步。

數字保險箱輸入正確密碼後，部分型號還要向下拉動把手。滾輪式密碼鎖需要將每一位拖到中央。錘擊時點選出現的目標；切割時按提示方向劃過畫面。商店的輔助道具可免費重複領取；需要自由選關時，可以在商店確認解鎖全部關卡。

場景裡的收集黃金鑰匙只計入一次收集進度。攻略中用於開鎖的金色鑰匙屬於解謎物品，請按對應位置使用。

配圖用於辨認機關與按鍵；其中部分為操作過程中的畫面，請按各節文字步驟完成設定。

## 第 1 章：房間裡的回憶

### 1-1：照片上的日期

1. 先檢視電視，聽完妻子的留言。她提到紀念日，因此先找能記錄日期的物件。
2. 從梳妝檯拿刷子，調查蒙塵的照片。對相框使用刷子，在特寫中左右擦拭，直到照片上的日期露出來。
3. 照片寫著 **08.17**。保險箱要求四位數字，去掉日期中間的點，就是 **0817**。
4. 輸入密碼，再向下拉動保險箱把手。拿走裡面的鑰匙，對出口門使用；開啟門後切換到移動模式離開。

**黃金鑰匙：** 前景圓桌上，照片右側、日記旁的桌沿處。切換到拾取模式點選小黃金鑰匙，離開前收好。

### 1-2：讓風扇吹出紙條

1. 檢視電視留言，再調查風扇：它缺少按鈕，直接點選不能啟動。
2. 拿地上的鉗子和衣架，在物品欄把兩者組合成鉤子。床底的狹窄位置夠不到，彎鉤正好能把裡面的按鈕勾出來。
3. 對床底使用鉤子，取得風扇按鈕；把按鈕裝回風扇，再啟動風扇。
4. 等扇葉轉動、紙條掉落後拾取紙條。紙條上的 **6614** 就是保險箱所需的四位密碼。
5. 輸入 **6614**，拉下把手，取鑰匙開門，再選擇移動離開。

**黃金鑰匙：** 向右拖動場景，到電腦桌前，在鍵盤左側的桌子前沿拾取。

### 1-3：歌名、曲長與燈光的影子

1. 檢視電視，拿床附近的芭蕾舞人偶。在地球儀附近的架子上拿 CD 盒，使用拆分得到 CD 和盒子。
2. 把人偶裝到八音盒上，隨後調查亮起的顯示器。螢幕提示的歌名是 **You are my Everything**。
3. 檢視 CD 盒上的曲目表，找到這首歌，其時長是 **03:27**。保險箱要四位數字，因此輸入 **0327**，拉下把手，取出形狀奇怪的鑰匙。
4. 開啟廚房櫃子，拿錘子。點選牆燈，使燈轉向左側，露出可插鑰匙的位置。
5. 對燈上的鑰匙孔使用奇怪的鑰匙。觀察投在牆上的影子：它提示錘擊的位置。對影子對應的牆面使用錘子，完成敲擊操作。
6. 拿出牆內的普通鑰匙，用它開出口門，再移動離開。

**黃金鑰匙：** 開啟最右側廚房紅色櫃子的抽屜，從裡面拾取。注意檢視抽屜，不要只開啟下面的櫃門。

### 1-4：讓三條鎖鏈依次鬆開

1. 觀察門上的三條鎖鏈，它們分別關聯電視、收音機和八音盒。先連續操作電視，直到電視開啟、對應鎖鏈解除；從初始狀態共需點選四次。
2. 開啟廚房抽屜拿電池，裝入收音機，再啟動收音機。第二條鎖鏈隨之解除。
3. 收集膠水及兩塊芭蕾舞人偶碎片。先組合碎片，再加膠水，得到修好的舞女人偶。
4. 開啟八音盒機關，轉動圓盤，讓各圈圖案拼接成完整圖案：紅色十字保持正向，底部較暗的背景彼此銜接。圖案完成後再安裝修好的人偶，等待八音盒和顯示器的反應，解除剩下的鎖鏈。
5. 調查 Beatles 海報，按人物從左到右讀衣服上的數字：**1、9、6、3**。把它們連成 **1963**，輸入保險箱並拉下把手。
6. 拿到鑰匙。確認三條鎖鏈均已解除，再用鑰匙開門，切換移動模式離開。

**黃金鑰匙：** 右側廚房餐桌的水果盤內，直接拾取。

### 1-5：日記裡的六個藏匿處

1. 檢視電視，再讀圓桌上的日記。兩頁畫著蘋果、地球儀、鏡子、香腸、玩具熊和相框，正好對應門邊的六個心形鑰匙槽。
2. 拿菜刀和地上的錘子。對玩具熊使用菜刀，按提示切開，取得一把心形鑰匙。
3. 分別用錘子敲開鏡子、地球儀和相框，各取一把心形鑰匙。
4. 從冰箱拿香腸，用拆分取出其中的鑰匙。另從桌上拿蘋果，在物品欄將蘋果與菜刀組合，取得最後一把鑰匙。
5. 將六把心形鑰匙逐一放進門邊相應的槽位。機關解開後開啟保險箱，取舊鑰匙。
6. 用舊鑰匙開出口門，鑰匙會折斷。改用錘子對門完成兩輪敲擊，開啟並穿過門；繼續開啟最後一道門，完成本章。

**黃金鑰匙：** 前景圓桌上，照片右側、檯燈底座附近。它與六把心形解謎鑰匙分別拾取。

## 第 2 章：循著現場線索前進

### 2-1：窗簾後的四個數字

1. 從桌上拿錘子，敲碎玻璃花瓶，拾取裡面的小鑰匙。小鑰匙能開啟上鎖的抽屜。
2. 開啟抽屜，拿到螺絲刀套裝。在物品欄連續拆分兩次，取出適合控制盒螺絲的星形螺絲刀。
3. 用它卸下百葉窗金屬控制盒的螺絲，再操作控制盒，開啟百葉窗；卸螺絲後還需要點選兩次。
4. 留意窗前出現的數字，按出現的順序記下 **0、2、1、3**。這給出了滾輪保險箱的四位密碼。
5. 把四個滾輪從左到右調到 **0213**，使數字落在中間讀數位置。拿鑰匙開門，然後移動離開。

**黃金鑰匙：** 對出口門旁的小窗戶使用錘子，敲碎玻璃後拾取。它位於大百葉窗的右側。

### 2-2：讓血跡顯出留言

1. 拿地上的金屬片和警用工具包。將物品欄中已有的包鑰匙與工具包組合，再連續拆分，取出說明書、噴霧器和魯米諾試劑。
2. 檢視說明書，得知試劑能讓血跡在黑暗中顯現。把噴霧器和試劑組合成可用的噴霧。
3. 用金屬片撬開電視櫃藏有剪刀的抽屜，拿剪刀剪開現場封鎖帶，才能接近裡面的血跡。
4. 對血跡使用噴霧，再關閉房間燈光。調查發光的血跡，讀出留言中的 **7230**；旁邊的名字幫助辨認這是一條留下來的資訊。
5. 重新開燈，開啟門邊的電子密碼裝置，輸入 **7230**。等門鎖解除，開門並移動離開。

**黃金鑰匙：** 用同一塊金屬片撬開電視櫃的另一隻下部抽屜。拿完剪刀後繼續檢查其他抽屜，黃金鑰匙就在其中。

### 2-3：眼睛給出的方向

1. 拿美工刀，割開遮住畫框的覆蓋物，再調查露出來的畫。觀察眼睛依次看向哪裡，記下 **上、下、左、右、上、右**。
2. 開啟箭頭機關，照這個順序按六次，取得小鑰匙。若沒記清，返回畫框再看一遍。
3. 小鑰匙分別開啟兩邊的櫃門，裡面是電鑽和電池。將它們組合，電鑽才可使用。
4. 出路在壁爐，但火擋住了通道。拿空罐，用電鑽鑽開水族箱，再用罐子接漏出的水。
5. 將水倒進壁爐滅火。取小凳子，調查壁爐並把凳子放進去；有了墊腳處，才能夠到上方通道。
6. 調查放好的凳子，再切換移動模式爬出去。

**黃金鑰匙：** 開啟右側掛畫下面木櫃的抽屜，直接拾取。

### 2-4：骷髏圖案與三組計算

1. 調查門上的 **6412**，再翻看顯示屏的六張骷髏圖。每張圖帶一個數字，建立“數字—骷髏外形”的對應關係。
2. 開啟右邊儲物櫃拿扳手，卸下固定鐵管的兩顆螺栓，取鐵管。用鐵管打碎門鎖裝置的玻璃罩。
3. 門鎖的按鈕畫著骷髏。按門上的 **6→4→1→2** 找對應圖案；按按鈕位置表示，就是 **下排左、下排右、上排右、上排左**。解鎖後進入下一間房。
4. 開啟電腦桌抽屜拿電源線，接到插座，啟動顯示器。翻閱三頁線索，它們分別對應 A、B、C 保險箱。
5. **A 箱：** 數字方陣要求每行、每列之和為 30。逐行、逐列補出彩色空格，再按下方 **綠、紅、藍、黃** 的順序讀取，得到 **1、8、5、6**，輸入 **1856**。
6. **B 箱：** 按螢幕下方列出的四種星形分類計數。四類數量依次是 **7、5、5、3**，輸入 **7553**。
7. **C 箱：** 每個扇區的三個數字相加為 18。按綠、紅、藍、黃讀數：18−4−8＝6，18−5−9＝4，18−7−2＝9，18−8−6＝4，因此輸入 **6494**。
8. 從三個保險箱取齊大、中、小齒輪，裝到出口機關的相應位置。轉動齒輪，讓圖案正向且互相銜接，完成後透過出口。

**黃金鑰匙：** 還在第一間房時，開啟左邊儲物櫃拿螺絲刀。用它卸開左牆的金屬蓋板，拾取裡面的黃金鑰匙，再去下一間房。

### 2-5：拼好開關位置圖

![配電箱開關](assets/switch.png)

1. 拉開窗簾，完成劇情。檢視書並開啟它，取小鑰匙，用鑰匙開啟抽屜，拿雙管槍。拾取倒下的椅子附近的第一張紙條碎片。
2. 搜尋編號櫃：1 號櫃有塑膠盒，拆開得到彈藥；3 號櫃有電線。先把電線取走，再調整櫃門。
3. 調查櫃旁的提示。5 號櫃的開鎖條件與另外四扇櫃門的開閉有關：讓 **1、4 號開啟，2、3 號關閉**，即可開啟 5 號櫃，取第三張紙條碎片；兩組數字都能配成 5，反過來的開閉組合也能解鎖。
4. 將彈藥與槍組合，對通道門使用兩次，進入走廊。拿鉗子和長椅附近的第二張紙條碎片。
5. 將三張紙條組合成完整便條。紙上兩排、每排五個小框，對應配電箱的十個開關；各框塗黑的位置給出了撥杆該放在哪一端。
6. 用鉗子與電線組合，得到兩端處理好的電線，裝進配電箱恢復連線。
7. 按便條設定開關。從左數，開啟 **上排第 2、5 個，下排第 2、4、5 個**，其餘關閉。裝置恢復後，開啟出口並離開。

**黃金鑰匙：** 開啟編號 **6** 的櫃子，拾取裡面的黃金鑰匙。拿完再離開第一間房。

## 第 3 章：指紋與秘密通道

### 3-1：找到按鍵，再複製指紋

1. 調查出口旁的裝置，發現它同時要求按鍵輸入和指紋識別。按鍵上留有指紋，但直接看不清。
2. 從筆筒拿毛筆，拿裝有鋁粉的瓶子，把兩者組合。開啟抽屜拿膠帶，並拿桌上的印泥。
3. 對門邊裝置使用蘸粉的毛筆，進入特寫後觀察顯出的痕跡。帶有指紋的是 **0、1、6、7**，選中這四個按鍵，等待掃描完成。
4. 裝置仍需正確的指紋。調查老闆最後按過的警報開關，這裡保留了他的指紋。
5. 在物品欄拆分膠帶，取膠帶碎片與印泥組合。把處理好的膠帶用在警報開關上，得到印有指紋的膠帶。
6. 將指紋膠帶用於門邊識別器。識別成功後開門，切換移動模式透過出口。

**黃金鑰匙：** 老闆坐著的椅子座墊前沿，靠桌子下方的位置，直接拾取。

### 3-2：數投影裡的顏色

![電路連線](assets/circuit.png)

1. 拿沙發下的錘子，敲開 DVD 櫃玻璃，取電池。拿茶几上的遙控器，與電池組合後用於牆上的投影儀。
2. 投影開始播放四色圖案。先記下牆上的顏色順序，再分別數圖案中對應顏色的部分：**藍 4、黃 5、紅 4、綠 5**，得到保險箱密碼 **4545**。
3. 保險箱藏在幕布後，但幕布控制器沒有電。開啟右側抽屜拿螺絲刀，卸下金屬電路盒的螺絲，再開啟盒蓋。
4. 電路要沿相鄰圓點連通。從初始亮點出發，依次走：**右、上、右、右、右、右、下、左、左、左、下、右、右、下、右、上、右、上、右、上**。每點一次，等點亮動畫完成再點下一點。
5. 電路恢復後操作幕布控制器，把幕布升起，找到後面的保險箱。輸入 **4545**，拉下把手，拿鑰匙。
6. 用鑰匙開出口門，再移動離開。

**黃金鑰匙：** 茶几右側的玻璃下。先用錘子敲碎該處玻璃，完成敲擊後再拾取；看到鑰匙時還不能隔著玻璃直接拿。

### 3-3：樂譜空隙中的數字

1. 調查牆上的樂譜，在特寫中橫向拖動，把整段譜子看完。留意音符和連線之間的空白，它們組成了數字；按譜面箭頭所指的方向讀取，得到 **4710**。
2. 在平板裝置輸入 **4710**，開啟儲物空間，拿火藥和引線。繼續搜尋抽屜，取藍色膠帶和打火機。
3. 開啟冰箱，拿封著鑰匙的冰塊；另從爐灶附近拿鑷子。鑰匙不能直接從冰裡取出，需要先融冰。
4. 把冰塊放入玻璃水壺，開啟對應爐灶開關。等冰融化後，用鑷子夾出熱水裡的鑰匙。
5. 在物品欄將火藥與引線組合，再與藍色膠帶組合，得到本關的貼上炸藥道具。將它貼在廚房出口門上，用打火機觸發開門劇情。
6. 透過破開的門回到走廊，再用剛取出的鑰匙開啟衣帽間門，進入下一關。

**黃金鑰匙：** 開啟冰箱後，在冰箱裡面拾取。拿冰塊時一併檢查。

### 3-4：從 BLUE SHIRT 推到 VASE

![鐘錶機關](assets/watch.png)

1. 拾取衣帽間地上的紙條，記下兩行數字：**4、1、8、12 / 9、7、5、2、10**。再觀察地板花紋，與中央門上的九宮格比較。
2. 按地板的對應位置點亮 **左上、右上、正中、右下** 四格，開啟暗道，進入書房。
3. 拿書房裡的短刀，調查編號書脊。按紙條給出的順序取字母：4=B、1=L、8=U、12=E，9=S、7=H、5=I、2=R、10=T，拼成 **BLUE SHIRT（藍色襯衫）**。
4. 返回衣帽間，用短刀切開藍色襯衫，拿掉出的普通小鑰匙；用它開啟房間中央的儲物櫃，露出四隻手錶的機關。
5. 回書房調查指南針與牆鍾：指南針的紅針表示北方，牆鐘的紅針停在五點方向。把“五點方向＝北”作為旋轉後的方位基準，判斷四隻錶針分別指向 **W、S、N、E**。
6. 將手錶下方的字母調為 **W、S、N、E**。從初始狀態起，四個按鈕依次點選 **1、2、3、0 次**。成功後四根錶針轉到 **3、6、9、12** 點。

4. 用錘子敲開藍色箱子，拿金盃，放到左側敞開的對應展位。裝置顯示 **3846**；在儲藏室保險箱輸入它，取金色半圓模型。
5. 回主房間，用十字螺絲刀開啟左側供電裝置，拿走壞電源，換上新電源，讓光束照向女像底座。
6. 將半圓模型與右牆高處的另一半拼成完整圓形，露出四顆寶石。
7. 拆分十字螺絲刀，保留手柄，與一字刀頭組合。用一字螺絲刀逐一撬下四顆寶石。
8. 按女像顏色安裝寶石，四個位置從左到右為 **紅、藍、綠、紫**。光線經寶石折射後，出口開啟，進入電梯。

**黃金鑰匙：** 儲藏室後牆的玻璃裡。用錘子敲碎玻璃，拾取裡面的黃金鑰匙，再返回主房間。

### 5-5：把門上的圖案踩在地板上

1. 電梯門上方顯示 **15679**，但操作面板需要較短的數字。把各位相加：**1＋5＋6＋7＋9＝28**，在右側面板輸入 **28**。
2. 電梯門開啟後，玻璃門上出現混排的 **PUSH / PULL** 字母。辨認朝向自己一面的“推”，在字母裝置輸入 **PUSH**。
3. 進入最後的大廳，聽完關於地板機關的提醒。觀察遠端門上發光的圖案，形狀像大寫 **I**，要在地板上照樣點亮。
4. 切換到移動模式。以畫面上方為第一排，從左到右踩亮第一排五塊，再踩第二排中間、第三排中間，最後從左到右踩亮第四排五塊。
5. 完成的圖案應是上下兩條橫線，中間一條豎線。出口開啟後，先拿出現的黃金鑰匙，再移動透過出口。

**黃金鑰匙：** 完成地板機關後才會出現，位於開啟的出口附近。離開前切換回拾取模式拿走。

## 第 6 章

### 6-1：把鐵管做成撬杆

1. 調查木門縫隙，發現門外有掛鉤，手伸進去也夠不到。撿鐵絲團，在物品欄拆分，取末端彎曲的長鐵絲，用它勾下門外的掛鉤。
2. 切換手形開門，再用移動模式進入工房。前方大門被鐵鏈鎖住，調查地板上的地下通道，發現蓋板左邊有窄縫。
3. 拿地上的沉重鐵塊、普通鐵管和揹包。連續拆分揹包，直到取出手電筒、繩索和行動式刀。
4. 圓頭鐵管塞不進窄縫，需要把一端壓扁。用刀撬開牆上的金屬開關盒，把普通鐵管放在懸吊鐵塊正下方的鋼板上。
5. 按開關讓鐵塊落下，將鐵管的一端壓扁；加工後的鐵管會進入物品欄。
6. 單靠鐵管還使不上力。在地下通道蓋板左側放下沉重鐵塊作支點，再對蓋板使用加工後的鐵管，以槓桿撬開蓋板。
7. 拿完黃金鑰匙後，切換移動模式，從開啟的地下通道下去。

**黃金鑰匙：** 工房內，鐵鏈大門右側的小櫃檯上，位於小螢幕下方。進入工房後即可拾取。

### 6-2：找齊零件，再拼回機器

1. 點選天花板的小燈泡開燈，調查木箱後的人並完成對話。開啟牆上的操作裝置，確認內部缺少零件。
2. 收集直接露出的 **2、4、5、8 號零件**，分別留意中央地面、沙發前地面、左下地面及地板櫃前方。
3. 開啟牆上的小櫃子拿 **1 號**，開啟地板左櫃拿 **9 號**、右櫃拿 **6 號**；掀開沙發上的布拿 **7 號**。
4. 拿錘子，調查右側封住的木板，縫裡有閃光。用錘子敲開，拿 **3 號**。物品欄應已集齊九件。
5. 把九件零件逐一用於開啟的操作裝置，再點裝置進入拼圖。把右側零件拖進左側凹槽；放對會吸附，放偏會退回。
6. 按外形拼合：帶兩個白色圓筒的長角形放左上；折線連桿放它下方；細長活塞放上方中間；黃色方塊放左側中部；大塊多孔機件放中下；另一個角形連桿放左下。
7. 右側豎條由上到下放渦輪機件、三孔 T 形連桿、帶燈泡的角形機件。利用凹槽中已有的兩塊固定機件對齊邊緣，拼滿後出口燈亮、門開啟。
8. 完成對話，拿完黃金鑰匙，透過右側出口。

**黃金鑰匙：** 開燈後看左上牆面，位於左側紅燈下方、橫向管道左端附近。用手拾取。

### 6-3：把映象紙條翻回來

![保險絲映象紙條](assets/clues/fuse-note-back.png)

1. 拿錘子、地面兩張紙條和露出的 **1、3 號保險絲**。掀地上的布拿 **2 號**，開左側櫃子拿 **4 號**，用錘子敲開卡住的抽屜拿 **5 號**。
2. 檢視兩張紙條。第一張的“open device”正常，黑點在左上、右上、左下；第二張文字左右顛倒，因此彩點也要左右翻轉後再對應。
3. 翻轉後的顏色是 **左上紅、右上藍、左下黃**。對照保險絲物品圖：**1 號紅、3 號藍、4 號黃**。把它們分別放進左上、右上、左下槽，中央和右下留空。
4. 按裝置按鈕，使下方儲物箱的密碼鎖可用。調查電視，留意新聞中人物胸前牌子的 **9764**，這是箱子的四位密碼。
5. 點儲物箱，輸入 **9764** 後拉動把手，拿裝置鑰匙。
6. 透過旁邊的門進入相鄰房間，對拉桿附近的鑰匙孔使用裝置鑰匙，指示燈亮起後拉動拉桿。聽到隔壁開門聲，返回原房間。
7. 拿完黃金鑰匙，從現在開啟的出口離開。

**黃金鑰匙：** 初始房間的前景地面上，在散落紙張旁、長條控制面板左下方。無需開啟密碼箱即可拿取。

### 6-4：凍住門鎖再敲碎

1. 揭開中央機器的罩布，發現這是冷卻裝置。收集錘子、把手和空瓶，開啟右側抽屜拿舊鑰匙。
2. 對出口鎖使用舊鑰匙，鑰匙會折斷，說明需要另一種辦法。調查冷卻裝置，發現噴口因生鏽無法轉動。
3. 把把手裝到大油桶的閥門上，轉動把手。潤滑油流出後，用空瓶接油，得到裝滿潤滑油的瓶子。
4. 對生鏽的冷卻裝置使用潤滑油，讓三個噴口恢復轉動。目標是讓三道冷氣都射向出口鎖。
5. 從剛上油的初始位置開始，保持最上噴口不動，**中間噴口點選兩次，最下噴口點選一次**，然後按啟動按鈕。
6. 冷氣噴到鎖上後，鎖結冰。用錘子敲碎凍住的鎖，再用手開啟門，切換移動模式離開。

**黃金鑰匙：** 房間上方，中央機器正上面的天花板橫管附近。拾取時注意點選管道邊的小金色鑰匙。

### 6-5：恢復供電，爬上最後的通道

1. 收集氧氣瓶、燃氣瓶、切割器、美工刀和鉤子。開啟桌子的上、下抽屜，各拿一支鉛筆。
2. 應急發電機的蓋板固定得很牢。先在物品欄把切割器與氧氣瓶組合，再與燃氣瓶組合，得到可用的氧氣切割器。
3. 用完成的切割器切開發電機蓋板，再用手按露出的啟動按鈕。
4. 調查牆上的兩處斷線。鉛筆芯中的石墨能夠導電：分別將美工刀與兩支鉛筆組合，削出兩根石墨芯。
5. 把 **石墨芯 1 放右側接點，石墨芯 2 放左側接點**，接通兩處斷線。恢復供電後透過門進入下一間。
6. 拿地上的鑰匙和柱子旁的繩索，把鉤子與繩索組合成鉤繩。觀察天花板上的通道，在繩索安裝處使用鉤繩。
7. 先開啟左側牆上的小櫃，收集最後一把黃金鑰匙，再切換移動模式沿繩爬上去。
8. 對最後的門鎖使用普通鑰匙，用手開啟門，再用移動模式透過，完成逃脫。

**黃金鑰匙：** 第二個房間左牆、控制檯上方的小櫃裡。用手開啟櫃門後拾取；地上拿到的普通鑰匙用於最後一道門鎖。
