# RoomBreak Escape Now

![RoomBreak Escape Now タイトル画面](media/title.png)

## もう一度、あの扉を開こう

『RoomBreak: Escape Now!!』は GAMEDAY による物語形式の脱出ゲームです。米国の iOS 版は [2011 年 9 月 23 日に発売](https://gamefaqs.gamespot.com/iphone/644223-roombreak-escape-now/data)されました。六つの物語と三十のステージを巡り、手掛かりを探し、アイテムを組み合わせ、仕掛けを解き、ハンマーやナイフを使って先へ進みます。

旧版は初期のモバイル端末や古い実行環境に依存しており、現在のスマートフォンやパソコンで遊び直すことが難しくなっています。本プロジェクトは **macOS・Windows・Android・iOS 向けのネイティブアプリ**を目指し、懐かしい部屋、音、物語を今の端末で再び楽しめるようにする取り組みです。

韓国の企業情報サイト Bizno には、GAMEDAY Inc.（登録番号 617-81-59967）が [2021 年 2 月 17 日に廃業](https://bizno.net/article/6178159967)したと記載されています。これは同サイトが収録した事業状況の記録であり、原作コンテンツの権利は引き続き各権利者に帰属します。

## 今の環境で楽しむ

- 全六章、三十の本編ステージ。チュートリアル、物語、アイテム合成、仕掛けのミニゲームも収録。
- ゲーム内言語は中国語・英語・日本語・韓国語。マウスとタッチ操作に対応。
- ショップの商品はオフラインで無料入手でき、元の商品ごとの個数を維持。繰り返し入手可能。
- 新規セーブ時の初期アイテム数は原版と同じ。以後の獲得と消費は保存され、再起動してもリセットされません。
- ショップの「全ステージ解放」は確認後に実行。
- 金の鍵は各ステージで一度だけ拾える収集品。入手状況はセーブに記録。

## おなじみの操作を、新しい実装で

原版 iOS ゲームは **Objective-C と cocos2d** を使用し、32 ビット iOS と OpenGL ES 向けに作られていました。本作では **C++ と Axmol 2.11.5** で実行基盤を書き直し、シーン、物語、アイテム、謎解き、音声、セーブ処理を四つのプラットフォームで共有しています。描画には現代のグラフィックスバックエンドを使用します。

原版の金庫ダイヤルにも修正を加えました。旧実装では一単位未満のドラッグ量がゼロに切り捨てられ、ゆっくりした細かな操作が反応しない場合がありました。新版では浮動小数点の精度を保ち、小さな動きでもダイヤルを回せます。画面の文字は従来の書体を保ちながら、高解像度ウィンドウでの鮮明さを改善しました。
